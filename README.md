# Teleprompter

Teleprompter para você clonar e usar. Fui obrigado a criar depois de milhares de projetos simples com milhares de anúncios.

Um arquivo só (`index.html`), sem instalação, sem dependências, sem anúncio.

## Como usar

```bash
git clone https://github.com/JoaoVitorLima242/teleprompter.git
open teleprompter/index.html
```

Ou só baixe o `index.html` e abra no navegador.

- **⚙ Config**: cola o texto (sem limite) e ajusta fonte, velocidade, cor do fundo e do texto
- **▶ Play / ⏸ Pause**: botão, clique no texto ou `Espaço`
- **⛶ Tela cheia**: botão ou `F`
- Rolar com mouse/dedo volta ou adianta o texto, e ele continua descendo dali
- Texto e configurações ficam salvos no navegador
